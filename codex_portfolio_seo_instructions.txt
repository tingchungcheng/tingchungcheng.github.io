creating a conflicting file.

B. robots.txt Create or update robots.txt at the public root: - Allow
normal crawling of public pages. - Include the absolute sitemap URL. -
Do not block CSS, JavaScript, images, or the entire site. - Do not add
noindex directives.

C. GitHub Pages compatibility - Confirm sitemap.xml and robots.txt are
copied to the final deployment output. - Account for framework base
paths and asset paths. - Do not assume repository-root files are
automatically served at the deployed root; inspect build output. -
Preserve existing GitHub Actions/Pages deployment unless a correction is
necessary.

D. Crawlability - Check for accidental noindex tags or other directives
preventing indexing. - Ensure the deployed homepage returns a successful
response. - Avoid duplicate indexable URLs for identical content. - Do
not invent unnecessary routes or thin pages.

E. Structured data Add valid schema.org Person JSON-LD using only
verified facts: - @context - @type: Person - name: Ting Chung Cheng -
url: https://tingchungcheng.github.io/ - sameAs: verified GitHub and
LinkedIn profile URLs - jobTitle: accurate title already stated on the
portfolio - knowsAbout: only skills supported by the portfolio - image:
only if a real public profile image exists

Do not invent employer, address, phone number, awards, education, or
social accounts. Validate JSON syntax and ensure JSON-LD appears in
rendered HTML.
